# 2026-11-12 인물 사진으로 앱 끝까지 실행 · 시연 녹화

## Problem

11/10까지 실제 인물 사진(R1)은 실험 스크립트로만 생성해 봤고, 앱 안에서 등록 → 영역 지정 → Preview → 채택 → DP Plan → 공유 → 직원 화면까지 이어서 돌려 본 적이 없었다. 최종 미팅에 가져갈 시연 영상도 아직 없었다.

## Context

- 11/12 교수 미팅에서 최종 미팅이 11/13(금)에서 **11/17(화)**로 바뀜 (교수님 일정). 각자 최종 결과물을 시연·발표
- 학교 PC 코드는 PR #20 상태 → `git pull`로 PR #21~#25 반영 ("인물 사진" 라벨, D30 안내 문구)
- 입력: `R1.jpg`(상반신, 회색 반팔 포켓 티), `red_tee.jpg`

## AI 활용 목적 / Proposal

- Claude: 학교 PC 코드 상태 확인, 생성 결과 판정, 실험값과 영역 비교로 실패 원인 분석, 내장 브라우저로 영역 수정·나머지 단계 리허설, 시연 순서 작성, 녹화본 편집
- 앱 실행·녹화는 사용자

## Experiment (리허설 작업 #18)

| 회차 | 영역 (0~1) | 아래 끝 | 에디터 비율 안내 | 결과 |
| --- | --- | --- | --- | --- |
| 1차 (사용자) | x .21 y .25 w .66 h .72 | .97 | — | **실패** |
| 2차 (사용자) | x .21 y .26 w .66 h .71 | .97 | 영역 1.4 · 상품 1.2 "비슷합니다" | **실패** (1차와 같음) |
| 3차 (Claude, 아래 변만 올림) | x .21 y .26 w .66 h .57 | .83 | 영역 1.2 · 상품 1.2 "비슷합니다" | 통과 |
| 참고: 11/10 실험 R1 seed 42 | x .20 y .26 w .68 h .57 | .83 | — | 통과 |

1·2차 실패 내용: 영역이 티 밑단 아래 바지까지 덮어, **검정 바지가 파란 청바지로 바뀌고 티가 엉덩이까지 길어짐**. 팔 피부색도 원본보다 붉어지고 왼쪽 벽에 세로 경계선이 보임.

3차 이후 단계: 채택 → DP Plan(인물 사진 · AI Preview · 실제 상품 3열) → 작업 지시 → 작성 완료 → 매장에 공유 → 직원 화면(`&mode=view`, "확정된 DP Plan · 확인 전용", 버튼 없음) 모두 정상.

## 발견

1. **실패 원인은 모델이 아니라 영역 높이였다.** 같은 seed 42에서 아래 끝만 .97 → .83으로 바꾸자 실험 결과와 같아짐. AnyDoor는 영역 안을 모두 상품으로 다시 그리므로, 영역이 바지를 덮으면 바지도 새로 그린다
2. **에디터 비율 안내는 이 실수를 잡지 못한다.** 비율 차이 허용 범위가 1.5배라 1.4 vs 1.2도 "비슷합니다"로 표시됨. 안내는 모양만 비교하고, 영역이 옷 밖(바지)까지 덮는지는 알 수 없다
3. **화면 안내 "목선부터 밑단까지"만으로는 아래 끝 위치가 충분히 전달되지 않았다.** 사용자가 안내를 읽고도 두 번 바지까지 잡음
4. **공유 후에는 "직원 화면 미리보기" 버튼이 사라진다** (공유 완료 = 보기 상태라 버튼 줄 전체가 숨겨짐). 직원 화면은 주소에 `&mode=view`를 직접 붙여야 열림. 녹화 중 이 방법을 찾느라 약 1분이 들어감
5. 라벨 통일(11/10)에서 빠진 곳 2개 발견: Preview·DP Plan의 BEFORE 옆 "현재 매장"

## AI 오류와 정정

- Claude가 처음에 "크기 조절 핸들은 네 모서리에만 있다"고 안내 → 실제 화면을 열어 보니 변 가운데에도 핸들이 있었고, 3차 수정도 아래 변 가운데 핸들로 함. 코드 일부만 보고 단정한 잘못된 설명
- Claude가 쓴 시연 순서 표에서 작업 지시 문장과 버튼 순서("→ 작성 완료 → 매장에 공유")를 한 칸에 붙여 써서, 사용자가 화살표 부분까지 작업 지시로 입력함 → 입력 문장만 따로 다시 안내
- 수정한 라벨이 바로 안 보인 원인: 앱이 다시 빌드되지 않아 `build` 폴더에 예전 파일이 남아 있었음 → 앱 정지 → Rebuild → 재실행으로 반영
