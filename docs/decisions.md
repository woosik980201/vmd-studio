# 주요 결정 (Decision Log)

각 결정의 **주체(누가 판단했나)**, **근거(무엇을 확인했나)**, **영향(다음 설계에 어떻게 반영됐나)**을 남깁니다.

**주체 표기**
- **교수님** — 교수 미팅에서 받은 방향·피드백
- **사용자** — 본인이 직접 판단한 결정
- **AI 제안 → 사용자** — AI가 제안하고 본인이 검토해 채택·수정·거절한 결정
- **사용자 제안 → AI 구체화** — 본인이 문제나 아이디어를 내고 AI가 구현 방식을 정리한 결정

최종 채택 여부는 모든 경우 사용자가 판단했습니다. 기록에 제안자가 남지 않았던 D2~D9의 주체는 10/27에 사용자가 직접 확인했습니다.

## AI 제안을 그대로 받지 않은 사례

- 채택 확인 팝업 제안 → **거절** (D10)
- Store Setup 필수 항목 확대 → 적용했다가 재검토 후 **원래 조건으로 되돌림**
- ChatGPT 외부 검토 → 코드와 대조해 일부 수용·일부 반박·일부 보류, 그 과정에서 실제 버그 발견 (D14)
- "같은 Seed인데 결과가 다른 건 GPU 계산 방식 때문"이라는 Claude 설명 → 코드 확인 후 **틀린 설명으로 정정** (Seed 미적용이 원인, [10/27 기록](devlog/2026-10-27_anydoor-ai-server.md))
- "영역 크기 조절 핸들은 네 모서리에만 있다"는 Claude 안내 → 실제 화면 확인 후 **틀린 설명으로 정정** (변 가운데에도 있음, [11/12 기록](devlog/2026-11-12_app-run-and-recording.md))
